Live optical tracking

Tracking output starts OFF. Select a camera, click a distinct high-contrast feature, confirm the lock box, then turn tracking ON only with the telescope clear to move.

Recover camera turns optical motor output OFF and restarts only the vision/camera service. The telescope bridge remains running, and this page reconnects automatically.

Camera exposure and gain

Automatic is the default. Manual values are used only when automatic exposure and gain is unchecked. Hardware limits are read from the selected Pi camera; USB cameras without control enumeration retain conservative fallback limits.

Required before optical motor output. RESUME / ON runs this automatically when no valid mapping exists. Each axis probe now starts at no more than 0.05° and increases only when the feature moves less than 3 pixels, never exceeding the selected maximum. The telescope measures the feature's pixel vector and encoder delta, returns at no more than level 2, saves the result, then begins tracking. Use slew level 1 when preserving a narrow-field lock matters.

Vibration and lost-lock handling

Default: OFF. When enabled, this limits commanded travel relative to fresh encoder readings captured when Apply is clicked. It is not tied to an older session or telescope power state.

Vibration filtering smooths short excursions below the threshold; a persistent change is accepted after three frames. Return mode commands the last encoder position where the feature was visible, then stops there while the camera attempts reacquisition. It does not perform an unbounded sky scan.

Click the live image to lock a high-contrast point. A fixed-size CSRT box follows the selected texture. If that exact feature is no longer credible, motor corrections freeze and the display shows REACQUIRING; tracking resumes only after the original feature produces two consistent, unique template matches. Click again with tracking OFF to choose another target.
